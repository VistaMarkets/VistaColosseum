## Rulings on the two author calls
**(a) Home feed empty state reachable only via `HomeScreen(feed:)`: outside this phase, not a gap.**
Spec 08 asks for the empty state "when the list is empty after reset or filtering". On Home neither can happen: `homeFeed` is
a fixed list, not Scenario data, reset restores it, and the Following / For You tabs never filtered it (`home_screen.dart:80-84`,
both read `homeFeed`; pre-existing). The spec asks to render the state when the list is empty, not to build a Following filter.
Building one would change the demo's default Home view (it opens on Following) — a product call. The empty-state code is real
(`home_screen.dart:87-96`), uses the shared widget, and its action is the same `AppShell.showExplore` helper the Wallet and
Followers tests drive end to end. Cost to record for the user: in the shipped app this path is unreachable, and `feed:` is a
test-only constructor seam. Open user question, carried: should Home's "Following" tab filter by `Scenario.followed`?
(With follows emptied, "Following" still shows every caller's calls.)

**(b) `TraderRecordPanel.unavailableNote` and Explore's "No matches" left unstyled: outside this phase, not a gap.**
- The spec's surfaces are Home feed, Arena list, Open orders, Positions, Receipts, Ledger, Following/Followers. The record
  panel is none of them: it is a metric panel, and its note is VC-MKT-002's "zero settled calls shows unavailable" statement,
  pinned verbatim by phase 7 tests. `VistaEmptyState` requires one action and the panel has no honest one ("Explore markets"
  does not give a trader a record). Digest 7 suggested restyling it, but that line is digest guidance, not one of the manager
  decisions in `house-rules.md`; only the Profile CALLS change is labelled a manager decision (F8), and that one was done
  (`profile_screen.dart:359-365`).
- Explore is on the spec only for its failure, which is built. Its search "No matches" (`markets_screen.dart:256-263`) is a
  search miss on an unlisted surface and does not throw. It is now inconsistent with the follow-list and Arena misses, which got
  a Clear search action; optional follow-up, not counted as a finding.
