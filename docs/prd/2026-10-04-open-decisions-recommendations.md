**Date:** October 4, 2026 · **Status:** decided; folded into [master PRD §8](2026-10-01-vc-hackathon-master-prd.md#8-open-decisions) and the [roadmap](2026-10-01-vc-hackathon-roadmap.md). As of October 4, the PRD listed eleven open decisions (O-01 to O-11), and the four M0 decisions were on the critical path. This document proposed a default for each decision; the **Decision** column records the user's answer of October 4. Where the answer overrode the default (O-02, O-04, O-05, O-06), the PRD and roadmap follow the answer, not the default. O-11 was left unanswered and stays open under its interim default.

Three facts from the current repository change the picture from October 2:

- The app was **Flutter** with `android/` and `ios/` targets only (a Linux desktop target was added October 12, PR #46).
- The shell already ships **four tabs: Home, Explore, Arena, Wallet** ([app_shell.dart](../../app/lib/app_shell.dart#L37-L40)), with Open Runde (OFL) bundled as the SF Pro Rounded substitute ([pubspec.yaml](../../app/pubspec.yaml)).
- **129 SVG assets exported from Figma** already live in `app/assets/figma/`. Someone had export access, so the Figma gap (O-09) is a process gap, not an access gap.

## What changed in the plans

- **Cutoff** was set to October 11, 23:00 America/Los_Angeles; corrected on October 5 to 2026-10-12 23:59.
- **Two developers.** The roadmap now runs frontend and backend streams in parallel from M2. The backend stream is the mock scenario store and ledger, since nothing goes live.
- **iOS Simulator** replaces the browser proposal. It only runs on macOS; M1 proved it on a Mac on October 5. The Linux desktop build became the fallback (rehearsal 1, October 12).
- **Video economics** are reproduced as given. The simulation indicator stays because it marks demo money, not product claims. The known-limitations note will say the economics are a demo narrative.
- **Copy/payment story is P0** with a fixture rule: copier pays a flat $5.00 demo fee on a confirmed copy, creator gets it as a `copy` ledger credit. Change the numbers in VC-CPY-002 if you want different ones.
- **Still open after M0:** the O-09 Figma frame export and an answer on O-11. The O-08 coverage audit was done in the M2–M5 records.
