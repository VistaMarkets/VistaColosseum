## State

- **Where it lives.** `Scenario` (`app/lib/scenario/scenario.dart`) answers the user's own cap in `int` cents. It is derived, at read time, from state `Scenario` already holds (`hasMarket`, `listedAt`, `marketId`); nothing else in `Scenario` stores a cap, and the success step keeps one read-once copy (Readers). Every listing path runs through `AccountState.listMarket` (`account_state.dart:17-22`, outside this job's file set), which sets `listedAt` to the clock and `hasMarket` to true, so a derived value is set on listing by every caller, the flow and the tests alike, with no new write.
- **Shape.**
  - `static int? get ownCapCents` — `null` when `hasMarket` is false or `listedAt` is null. The second case covers `reset(withMarket: true)` starting from no market: `hasMarket` is written before `listedAt` (`scenario.dart:454,457`), so between those writes a synchronous listener sees null, not $10,000. `YourMarketMock.seededCapCents` = `4400000000` ($44.0M) when the listing is the `HAS_MARKET` seed: `listedAt == YourMarketMock.listedAt` and `marketId == PortfolioMock.marketSymbol`. The `marketId` half keys the seed to its own market, as `marketFees` keys credits by `marketId` (`scenario.dart:196-205`), so a market under another id (`receipts_test.dart:173-176` sets `ZED`) reads as fresh. Otherwise `MakeMarketMock.startingCapCents` = `1000000` ($10,000).
  - `static bool get ownCapHasHistory` — `hasMarket` and the seed test above, as one getter. `ownCapCents`, `ownCapMoveCents` and both charts (through `ownCapSeries`) branch on it; nothing else re-tests the seed.
  - `static int ownCapMoveCents(int span)` — what the cap moved by over span index `span` of `PortfolioMock.spans`, in cents. It starts `RangeError.checkValidIndex(span, PortfolioMock.spans);`, so a bad index throws on every branch. When `ownCapHasHistory` it returns `YourMarketMock.seededCapMovesCents[span]` = `[-21000000, 35000000, 180000000, 560000000, -230000000, 3120000000]`, today's `_capMoves` in cents. Otherwise it returns `0` for every span when there is no history (a fresh listing) or no market (`ownCapCents` null).
  - `static final Listenable ownCap = Listenable.merge([hasMarket, listedAt, marketId])` — the three values the cap derives from, for readers to rebuild on. It is one instance, so a `ListenableBuilder` keeps its subscription across builds.
- **Set on listing.** Implicit, as above. A fresh listing's `listedAt` is the demo clock. No app code writes `Scenario.clock` (only `reset()` and tests do), so in the app it never equals the seed's instant (`TradeMock.chartEnd.subtract(const Duration(days: 7))`). ## Formatting

Three top-level functions in `app/lib/features/market/market_mock.dart` (a fixture file, because the job's file set has no shared formatter file), all `int` in, string out. `formatCap` asserts `cents >= 0 && cents < 99995000000` and `formatUnitPrice` asserts `capCents >= 0 && supplyUnits > 0`: adding half before `~/` rounds half-up only for non-negative values. The unit line prints the supply as `YourMarketMock.supplyUnits ~/ 1000000`, so Your market asserts `YourMarketMock.supplyUnits % 1000000 == 0` where it builds that line. Caps of $999.95M (`99995000000` cents) and above are out of range for this demo: `formatCap` would print `$1000.0M`, so its assert stops them.

- `formatCap(int cents)` — at or above $1M (`100000000` cents), tenths of a million `(cents + 5000000) ~/ 10000000`, printed `'\$${t ~/ 10}.${t % 10}M'` for that quotient `t` (`$44.0M`); below, whole dollars `(cents + 50) ~/ 100` printed with the thousands-separator regex `formatCents` uses (`live_feed.dart:68-76`), not `formatUsd`, which takes a `double` (`$10,000`). Both round half-up, so `99999950`..`99999999` cents print `$1,000,000` and `100000000` prints `$1.0M`.
- `formatCapChange(int startCents, int endCents)` — sign (`+` for no move or a rise, U+2212 `−` for a fall, the sign `formatUsd` and `formatCents` print (`live_feed.dart:62,74`), never ASCII `-`), the absolute move through `formatCap`, then the percentage of `startCents` in hundredths, half-up, `(move.abs() * 20000 + startCents) ~/ (2 * startCents)` with `move = endCents - startCents`, printed `' (${p ~/ 100}.${(p % 100).toString().padLeft(2, '0')}%)'` for that quotient `p`; no percentage when `startCents <= 0`. Seed 1D: `+$1.8M (4.27%)`, 1h `−$210,000 (0.48%)`, 1M `−$2.3M (4.97%)`; truncating would print 4.26%, 0.47%, 4.96%. Seed 4h: `+$350,000 (0.80%)`. Sub-$1M moves (1h, 4h) now print whole dollars, not today's `−$0.2M` / `+$0.3M`: intended. Fresh listing: `+$0 (0.00%)`.
- `formatUnitPrice(int capCents, int supplyUnits)` — ten-thousandths of a dollar, half-up, `t = (capCents * 100 + supplyUnits ~/ 2) ~/ supplyUnits`, printed `'\$${t ~/ 10000}.${(t % 10000).toString().padLeft(4, '0')}'`: $44.0M → `$0.4400`, $10,000 → `$0.0001`. Four decimals are accepted: every cap from $5,000 to $14,999.99 prints `$0.0001`.

## Chart handling

**Decision: flatten.** A market listed at the demo's now has no cap history, so its chart is flat, not scaled. Scaling the seed's moves down to $10,000 would invent growth for a market seconds old. The flat line covers every span, Past week and All time included. That is accepted as truthful because the cap has not moved since listing, and the change line reads `+$0 (0.00%)`. The accepted consequence is a window label such as `Past week` over a market seconds old. Remaining risk (author decision): the seed's 1M and All moves predate its `listedAt` (a week before the clock); they stay as fixture history.

- Wallet: `List<double>? ownCapSeries(int span)` (top-level, in `market_mock.dart` beside the formatters; it imports `bridgeSeries` from `portfolio/series_chart.dart`, so Your market reads it without importing the Wallet pager), `null` when `Scenario.ownCapCents` is null. A fresh listing gets 48 copies of `cap / 100`. `bridgeSeries` is not used for a zero move because it still adds a 0.15% wiggle. Known cosmetic risk (owner: the user's approved file set, which leaves out `series_chart.dart` and `signal_replay_chart.dart`): a flat series maps to one height (`canvasY` returns 201.5 when `hi == lo`, `series_chart.dart:57-60`), and `ReplayLinePainter` strokes above and below that height in two colours (`signal_replay_chart.dart:725-797`).
