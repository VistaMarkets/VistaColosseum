# Domain docs

VC uses a single-context layout: `CONTEXT.md` at the repository root and
architecture decision records under `docs/adr/` when decisions are recorded.

## Before exploring

- Read root `CONTEXT.md` and use its vocabulary consistently.
- Read any ADRs relevant to the work under `docs/adr/`.
- If a referenced domain document or ADR directory does not exist, proceed
  without creating a placeholder. Add records when an actual term or decision
  is resolved.

## Vocabulary and decisions

Use glossary terms in code, issues, and documentation. Note a genuine gap
instead of inventing a conflicting synonym. Surface any conflict with an
existing ADR explicitly, naming the record and the proposed change.

The glossary and ADRs supplement the repository's safety and workflow rules.
They do not authorize broader scope or real financial actions.
